# 地球电视：首版需求与实施方案

状态：需求澄清完成，等待技术验证。更新：2026-10-14。

逐项实施任务、预期文件与验收步骤见[地球电视首版实施计划](../plans/2026-10-14-globe-tv-mvp.md)。

## 产品目标

做一个以 3D 地球为入口的网页直播电视应用。用户旋转地球、选中国家、浏览该国频道并点击播放。首版面向作者个人在中国大陆直连网络使用，网站通过公开网址访问，持有链接的人也可以打开。优先桌面浏览器，同时适配手机。界面使用简体中文，频道名称保留原文。此处的“节目列表”定义为**直播频道列表**，不包含节目时刻表。

首版只包含电视，不包含电台、摄像头、账号、跨设备数据同步、视频中转和频道分类筛选。持续费用目标为零；如果免费服务在实际网络下不稳定，再评估替代方案。

## 核心体验

1. 首次进入时展示缓慢自转的完整地球、简短引导和搜索入口。用户操作后停止自转，不自动播放。
2. 地球采用深色影院风：深蓝黑背景、简洁国界、低饱和陆地、柔和大气光。悬停或聚焦时显示国家名称和**收录频道数**；选中时高亮并平滑转向。可放大到国家级，小国家可通过搜索或国家列表选择。
3. 点击国家后显示频道列表。无频道的国家仍可选中，但降低亮度并提示暂无频道。国家内可以搜索频道；收藏优先，其余按名称排序。地区受限频道保留并标注“可能受地区限制”。仅有 YouTube 来源的频道默认隐藏。
4. 全局搜索同时查找中文或英文国家名称及原文频道名称。选国家时定位地球并展示列表；选频道时打开对应国家并开始播放。
5. 桌面端播放时右侧显示大播放器，地球缩小保留，频道列表仍可操作。切换浏览国家不会中断正在观看的直播；点击其他频道才切换。播放器显示当前频道和所属国家。
6. 手机端未播放时以地球为主；播放时播放器置顶，下方切换“地球 / 频道”。支持全屏、画中画（浏览器支持时）、播放/暂停、音量、静音和手动选择备用源。
7. 播放失败时自动依次尝试同频道备用源，显示尝试状态并允许取消。全部失败后显示重试与换台操作，不自动跳到其他频道。浏览器直接访问直播源，失败可能由源失效、跨域、地区限制或网络造成。
8. 收藏和最近观看存于当前浏览器，无需登录。最近观看应在实际开始播放后记录。提供国家和频道直达链接；频道直达页先展示对应频道，由用户点击开始播放。
9. 3D 地球无法运行时切换到国家列表，搜索、选台、播放仍可使用。

## 数据与同步

- 上游为 [Famelack TV 国家 JSON](https://github.com/famelack/famelack-data/tree/main/tv/raw/countries) 和 [国家元数据](https://raw.githubusercontent.com/famelack/famelack-data/main/tv/raw/countries_metadata.json)。频道记录含 `nanoid`、名称、国家代码、来源、语言及 `isGeoBlocked`；来源类型至少有 HLS 等 `streams` 和 `youtube`。实际字段以同步时校验为准。
- GitHub Actions 每天拉取上游，校验格式、标准化国家代码、过滤仅有 YouTube 来源的频道，并生成供网站读取的版本化数据。发布前保留上一次可用产物；若本次拉取或校验失败，则不覆盖已发布数据。
- 国家收录数应由**过滤后的频道数据**重新计算，不直接使用上游元数据中的 `channelCount`，避免地球标记与实际列表不一致。
- 频道稳定 ID 优先使用 `nanoid`；若上游删除频道，旧收藏和直达链接应显示“该频道已下线”，并允许清理收藏或返回国家列表。
- 上游提示结构可能变化，且不保证直接热链稳定，因此客户端读取本站打包数据。再分发数据时保留上游 MIT 许可证与版权声明，在应用中提供数据来源链接。[上游 README](https://github.com/famelack/famelack-data#readme)

## 技术方案

| 部分 | 首选方案 | 验证点 |
| --- | --- | --- |
| 前端 | React + TypeScript + Vite | 桌面、手机布局和构建体积 |
| 地球 | React Globe.GL + 本地国界 GeoJSON | 国界命中、选国动画、移动端帧率、WebGL 失败回退 |
| 播放 | HTML `video` 原生 HLS 优先；需要时用 hls.js | Safari、Chrome、Edge 的直播播放、跨域、错误恢复 |
| 状态 | React 组件状态；收藏和历史用 `localStorage` | 浏览国家与正在播放的频道独立维护 |
| 路由 | 国家与频道路径或查询参数 | 直达链接和静态托管回退 |
| 同步 | GitHub Actions 定时任务 | 数据校验、失败保留旧版本、许可证随产物保留 |
| 托管 | GitHub Pages 先实测；不稳定则验证 Cloudflare Workers 静态资源 | 中国大陆直连下的页面和资源加载 |

React Globe.GL 提供国家多边形点击等接口，适合国家级地球；具体性能仍需原型验证。[组件文档](https://github.com/vasturiano/react-globe.gl) hls.js 用于支持 Media Source Extensions 的浏览器，且要求 HLS 资源满足跨域请求条件；Safari 可走浏览器原生 HLS。播放器需根据实际能力选择路径，不能仅凭文件后缀认定可播放。[hls.js 文档](https://github.com/video-dev/hls.js)

Cloudflare Workers 可以托管静态资源并使用 `workers.dev` 域名；普通免费方案不等于 Cloudflare 中国网络，后者另有企业计划和备案要求。因此最终托管以作者本人在大陆直连网络下的实测为准。[Workers 静态资源](https://developers.cloudflare.com/workers/static-assets/) · [中国网络说明](https://developers.cloudflare.com/china-network/)

## 实施顺序

1. **技术验证**：用真实国界数据做地球选国原型；挑选中国及其他国家的 HLS、多备用源和失败源，在 Chrome、Edge、Safari 与手机上验证；分别打开 Pages 和 Workers 测试页检查大陆直连访问。
2. **数据管线**：完成上游拉取、结构校验、过滤、索引生成、国家数量重算、许可证保留和失败回退。为字段变更、空国家及重复频道编写针对性测试。
3. **核心界面**：实现地球、国家列表、全局搜索、国家频道列表、桌面与手机布局及直达链接。
4. **播放器与个人功能**：实现多源状态机、重试与取消、控制项、收藏和最近观看。
5. **视觉与验收**：完善动效和响应式细节，验证键盘操作、减少动态效果设置、无 WebGL 回退；在选定平台发布并记录实际播放与访问结果。

## 首版验收标准

- 桌面与手机均能完成“选国家 → 找频道 → 点击播放”；切换浏览国家时当前直播继续。
- 国家和频道搜索、直达链接、收藏及最近观看可用；清空网站存储后应用仍正常运行。
- 无频道、仅 YouTube 来源、地区限制、源加载失败和无 WebGL 均有清楚的界面反馈。
- 同一频道有多个源时能自动尝试下一个，并允许手动切换或取消。
- 每日同步失败不会让已发布频道列表变空；数据和许可证信息可追溯。
- 作者在中国大陆直连网络实测站点首页、地球资源和代表性频道；测试记录区分“代码支持”与“在该网络实际可播”。

## 尚需通过验证决定

- 具体国界数据集及其许可、体积和争议地区映射；采用一致的国家代码映射，避免地图与频道数据错位。
- 上游各种 `sources` 类型的实际分布；首版仅纳入浏览器可直接播放且可明确识别的类型。
- 代表性频道在作者网络中的可播放情况，以及失败来源占比。
- GitHub Pages 与 Workers 免费域名在作者网络中的实际访问表现。
