# 直播中文字幕：桌面 Chrome 零服务费用首版设计

日期：2026-10-15

## 目标与范围

公开站点的观众在电脑 Chrome 中观看外语 HLS 频道时，可以主动开启中文字幕。字幕固定显示在视频画面下方中央，包括播放器全屏状态。首版使用观众自己的浏览器捕获当前标签页音频、识别语音并翻译文字；站点不购买按音频时长计费的识别或翻译服务。用户接受字幕比声音慢一些。手机及其他浏览器在首版显示明确的替代操作说明。

这里的“零成本”指站点没有语音 API 用量账单；观众会消耗本机算力、网络流量，并可能下载语言包。浏览器管理的语音识别服务若在本机不可用，可能由浏览器厂商远程处理音频；在启用前告知观众，并提供仅允许本地识别的选项。站点不保存或上传音频、识别文本和译文。

## 用户流程

1. 播放器中提供“中文字幕”开关，默认关闭。开启时先选原语种，默认英语；语种由用户修改，不能只根据频道国家猜测。
2. 检测安全上下文、桌面 Chrome 所需的屏幕捕获、`SpeechRecognition.start(audioTrack)` 和 `Translator` 能力。需要语言包时展示下载状态。翻译器创建和屏幕共享分别在明确的用户操作中启动，以满足浏览器对用户手势的要求。
3. 浏览器请求共享当前标签页。界面提示观众选择“此标签页”并勾选共享标签页音频；拿不到音频轨时停止并给出可重试的说明。只使用音频轨进行识别，不读取或传输共享返回的视频轨；关闭会话时释放全部轨道。
4. 语音识别产生的最终语句进入顺序翻译队列，译成简体中文。播放器画面下方中央显示 1–2 行中文，长句自动换行；新句到达时替换旧句。允许关闭字幕。识别中间结果只用于状态反馈，不频繁翻译，避免字幕来回跳动。
5. 暂停时暂停识别并清空过期字幕；恢复播放时用仍有效的音频轨重启。换台或切换直播源时清空旧字幕和翻译队列，保留用户已授权的当前标签页音频轨并重启识别。关闭播放器或关闭字幕时停止识别、取消翻译任务并关闭所有捕获轨道。
6. 用户拒绝共享、选择了无音频的共享对象、停止共享、语言对不可用或浏览器不支持时，播放器显示具体原因和重试入口，并提供 Chrome 设置中“实时字幕／实时翻译”的操作指引；不让按钮呈现成功状态而一直没有字幕。

## 结构与边界

- `PlayerModal` 负责开关、原语种选择、播放器生命周期和字幕呈现。
- 独立的浏览器音频捕获模块负责请求授权、验证音频轨、监听轨道结束与释放资源。它不读取 HLS URL 或直接经过 Web Audio 解码跨域媒体。
- 独立的字幕会话模块负责能力检测、语音识别事件、最终语句去重、顺序翻译、过期结果丢弃和停止。会话以递增 ID 区分频道及直播源，旧异步结果不能写入新频道。
- 字幕节点放在 video.js 的全屏元素之内，使用 `pointer-events: none`，避开底部控制条和安全区域。文本使用高对比描边／半透明底，`aria-live="polite"` 应避免对每个识别中间结果播报。
- 语音识别优先使用浏览器支持的本地处理与语言包。仅在用户明确知情的情况下允许浏览器管理的远程识别。文字翻译使用 Chrome 桌面版 Translator API 和按需下载的语言包；检测不支持的语种组合时给出提示。

## 可行性关口

正式接入播放器前，先在当前站点与真实的外语 HLS 频道上验证：共享“此标签页”后有活动音频轨；播放声音仍正常；语音识别能持续拿到非空语句；所选语言到简体中文的翻译模型可用；普通窗口及 video.js 全屏都能显示字幕。至少覆盖两个不同来源的频道、暂停／恢复、换台、关播放器和用户主动停止共享。任何一项不成立，记录浏览器版本、频道来源和具体失败点，保留明确的替代指引，不将功能宣称为所有频道可用。

浏览器直接从跨域 HLS 读取 PCM 可能受 CORS 限制，因此此设计以用户授权的标签页捕获为主路径。字幕延迟、识别准确率、浏览器服务配额和语言包可用性都随设备、网络与语种变化；首版不承诺固定延迟或所有语言覆盖。

## 验收

- 受支持的桌面 Chrome 上，用户能在真实外语频道主动开启字幕，看到对应中文句子，字幕在画面下方中央，且全屏可见。
- 同一个频道有多名观众时，不产生站点端按观看时间增长的语音 API 账单。
- 拒绝授权、无音频轨、缺少语言包或浏览器能力、识别中断时，有可理解的状态和操作建议。
- 暂停、换台和切源不会残留旧字幕；关闭字幕及关闭播放器会释放全部捕获轨道；异步翻译结果不会串台。
- 类型检查、已有测试和生产构建通过；对依赖浏览器授权和真实直播源的行为做人工验证。

## 后续扩展

如果以后要求手机支持或降低每位观众的操作成本，可以增加按“频道 + 直播源”共享的服务端字幕会话：只在有观众订阅时拉取音频，识别一次并向多个观众分发，最后一位观众离开后停止。该扩展需要服务器、成本上限及直播源可由服务器读取的验证，单独设计和预算。
