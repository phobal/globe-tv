# 个人频道台交互设计

日期：2026-10-20
状态：交互方案已在讨论和线框中确认；本文待用户审阅。

## 目标与范围

将以地图探索为中心的 Globe TV 改为面向日常观看的个人频道台。用户主要观看几个固定频道，偶尔发现新内容。移除地图、地球和定位入口；同时支持电脑与手机。第一版免登录，收藏顺序、最近观看和引导状态保存在当前浏览器，不跨设备同步。

本次只改频道组织、导航、首页与播放交互。复用现有 Video.js 播放、多源失败重试、主题与字幕能力，不新增节目单服务、推荐算法、账号或云端同步。界面不根据未知信息声称频道可播、正在播某节目或具有某清晰度。

## 信息架构

主导航为「我的频道」和「发现频道」。播放是独立观看状态，不额外设置一个空的「正在播放」导航页。有播放会话时提供回到当前播放的入口。

### 我的频道

默认首页依次展示：

1. 继续观看：适中大小的上次观看入口，显示台标、频道名和按钮。点击才启动播放，不自动出声。直播重新进入当前直播，不能理解为恢复过去的直播时刻。
2. 我的收藏：紧凑台标网格，支持添加、移除和调整顺序；移动端提供明确的编辑模式，电脑与手机均有无需拖动的移动操作。
3. 最近看过：按成功开始播放的时间倒序，去重，最多保存 30 个频道。首页只展示少量条目，提供展开操作。

首次没有记录时隐藏继续观看；没有收藏时显示「添加常看的频道」和常用频道快捷入口。不强制进行设置，不把快捷入口标为实时热门。

旧频道 ID 仍存在时保留原收藏与记录；已移除的频道在收藏中显示不可用状态并允许移除，不跳到无关频道。台标失败时显示频道名缩写，保留完整名称。

### 发现频道

全局搜索覆盖频道名称，不受当前内容分类限制；搜索结果标出归属分类。一级内容分类固定为：

| 分类 | 范围 |
| --- | --- |
| 央视卫视 | 央视、各卫视 |
| 地方频道 | 各地地方电视台 |
| 体育 | 体育频道、赛事直播、赛事回放，区分内容类型 |
| 影视娱乐 | 影视轮播、综艺、音乐及歌手点播 |
| 少儿 | 少儿及动画频道 |
| 海外频道 | 海外电视，提供国家、语言次级筛选 |
| 更多 | 广播、实景直播与暂无法准确归类的内容 |

NewTV、百视通、iTV 等原始分组作为「来源分组」筛选，不直接占主导航。来源分组与播放器的具体「线路」是两个概念。国家、语言不再是主导航；国家字段缺失时不妨碍播放或收藏。

同一频道可出现在多个内容分类，频道 ID 保持唯一。收藏、最近观看和播放线路均绑定频道 ID。传统直播、赛事回放、点播有明确类型标识；首版不承诺点播进度恢复。

映射策略：为现有原始分组提供明确的默认分类，再以维护的频道 ID 映射覆盖或扩充分类。内容混合的来源分组不能整组武断归入某一主题；未确认归属的条目进入「更多」。允许编辑映射，不根据国家自动推断内容类型。分类数量由实际成员计算。

## 播放上下文与换台顺序

一次播放会话包含频道 ID、当前内容分类、该分类的有序频道 ID 列表、进入播放前的页面上下文。手机上下滑动只在此分类内切换，不跨分类，不接着刷全库。

从发现分类点入，使用当前分类；从收藏、最近或继续观看点入，恢复该频道上次使用的分类，若无记录则使用其主分类。收藏是快捷入口，不成为滑动队列。多分类频道的主分类由映射显式指定，不依赖文件遍历顺序。

分类内顺序采用稳定的中文名称排序，并用 ID 打破同名排序。一次有效纵向滑动只切换一台；首尾停留当前台，不循环、不自动跨分类。列表不足两台时不换台。打开「选台」可跳到当前分类中的任意频道；进入其他分类需要主动操作「浏览其他分类」。选台面板的列表滚动不触发换台。

搜索结果点入时采用结果标识的主分类。已在播放中的队列不随后台数据刷新而重排；下次主动进入分类再使用新列表。当前频道被删除时显示明确状态并允许重新选台。

## 电脑端

首页以收藏频道为视觉重点；发现页展示分类、搜索与频道网格。播放后主区域为播放器，右侧为当前分类频道列表。浏览分类或搜索不卸载当前播放实例；界面保留紧凑的当前播放入口。真正换台时才结束旧频道会话。

复用现有主题与字幕功能；不再展示地图侧栏、国家定位或地图错误状态。右侧列表清楚标识当前频道，收藏操作不会触发播放。

## 手机端沉浸播放

进入播放后，以一个频道占满可用播放页面，上滑下一台，下滑上一台。页面锁定背景滚动，尊重安全区。视频保持原始比例，横屏节目在竖屏中完整显示，不裁切填满。

### 操作浮层

所有播放操作叠在播放界面上：顶部为返回、当前分类与选台；下方为频道名、收藏、线路切换和全屏；中央为播放或暂停。不在播放器下方放上一台、下一台按钮，也不保留常驻的滑动方向文字。

在实际收到播放开始事件后，显示浮层并开始 3,000 毫秒计时；到时自动隐藏。轻触非控件区域显示浮层，并重新开始 3 秒计时。一次滑动后的合成点击不得误唤起或操作浮层。切到新频道后，加载期间可见，开始播放后再次按 3 秒隐藏。

暂停、等待用户授权播放、加载失败、首次引导、选台或线路面板打开、控件获得键盘焦点时，不自动隐藏。恢复播放或关闭面板后重新计时。隐去的控件不能继续点击或获得焦点；键盘操作可以唤回浮层。正常播放时的轻触仅唤回操作，不顺带暂停。

手势与交互控件隔离：在按钮、菜单、滑杆、字幕操作、错误恢复与引导层上操作时不换台。横向拖动、短拖动、多指触摸不换台；有效竖向手势不滚动背景。快速连续切换时旧频道的异步回调不能改变新频道状态。

全屏优先使用设备支持的播放器全屏；可用时尝试横屏锁定。浏览器不支持时仍能正常播放，不将锁定方向当作必需条件。

### 首次引导

只在当前浏览器首次进入手机播放页面时展示：

- 「上下滑动，切换频道」
- 「只在当前分类中切换」
- 「轻触画面，显示播放操作」
- 按钮「开始观看」

用户主动完成后记录版本化的引导状态。首次引导期间不启动自动隐藏计时，不接收换台手势。以后不再常驻提示。存储不可用时本次会话不重复提示；用户清除站点数据后允许重新引导。

## 数据与代码边界

以 public/data/category/*.json 为新目录数据源，生成轻量的频道摘要及分类索引；具体播放源可按原始分组延迟加载。原始 JSON 不承担界面导航定义，分类映射独立维护。对缺失分组、坏数据、同 ID 冲突提供构建诊断，不能静默丢失频道。

现有 category-report.json 的数量与目录当前数量不一致，因此索引、数量和报告应在同一次同步中从实际文件重新生成。应用不把报告中的旧总数写死。

建议职责边界：

- 数据层：目录生成、分类映射、摘要搜索、按需加载。
- 应用层：当前页面、播放会话、分类队列和导航恢复。
- 首页与发现页：频道呈现和用户操作，不拥有 Video.js 生命周期。
- 播放层：媒体播放、源状态机、浮层计时、手势、选台及引导。
- 偏好层：收藏顺序、最近观看、上次分类和引导状态，兼容旧存储。

复用 src/player/sourceMachine.ts 与字幕模块。现有 PlayerModal.tsx 同时承担媒体、手势、浮层与字幕；本次按职责抽出浮层计时和手机手势，避免继续堆叠条件分支。播放器容器改为可以持续挂载的观看区域。

新链接使用频道与内容分类，支持直接打开特定频道。旧 country / collection 链接中存在的频道 ID 迁移到新分类；仅有国家的旧链接打开海外频道对应筛选，只有旧热门集合的链接回到发现页。无效链接提供可操作提示，不回到地图。

## 播放失败与持久化

沿用现有多源顺序尝试与超时策略，手动切源保留。所有源失败后显示重试和选台入口，保持在当前频道；不擅自跳台。浏览器拦截自动播放时显示明确的播放按钮，不把权限限制当作线路无效而遍历线路。

最近观看仅在实际播放成功后更新。保存失败不阻塞使用；提示本次数据可能无法持久保存。兼容现有主题偏好。没有可恢复的历史频道时首页正常展示收藏和发现入口。

## 验证与验收

- 分类：每个有效频道至少属于一个一级分类；多分类不重复计入收藏；来源分组和线路严格分开；摘要计数与生成数据一致。
- 导航：收藏、搜索、分类及链接进入都产生明确的当前分类；滑动边界不跨类；返回恢复进入前页面与筛选。
- 播放：真实 playing 事件后 3 秒隐藏；轻触恢复；打开面板、暂停、失败或引导时不隐藏；隐藏控件不可交互。
- 触摸：上下滑动正确换台；横向、短拖动、多指及控件操作不换台；滑动后不触发合成点击；面板内列表可滚动。
- 持久化：收藏排序、最近观看、上次分类与引导状态能恢复；旧偏好可读；坏数据及存储受限可继续使用。
- 回归：现有源切换、字幕、主题和深链接测试继续有意义地通过；更新已被新设计替代的地图、国家队列断言。
- 自动检查：npm test、npm run typecheck、npm run build。浏览器检查手机窄屏与电脑布局，以及键盘操作。媒体真实播放与系统全屏在实际设备单独验证，不用占位线框代替。

## 实施顺序

1. 生成分类目录、映射及加载契约，保证新频道数据可用。
2. 迁移偏好与链接，建立独立的播放会话和分类队列。
3. 完成我的频道与发现页，替换地图入口。
4. 调整电脑播放布局与手机沉浸播放、浮层、首次引导。
5. 执行数据、交互、构建与设备回归，移除未使用的地图依赖并更新说明。

以上为同一交互改版的顺序步骤；每步保持可验证，不额外扩张产品范围。
