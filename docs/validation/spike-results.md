# 技术验证记录

日期：2026-10-14。当前记录区分代码验证与设备/网络实测。

## 已完成的代码验证

- 已用 Famelack `cn.json` 的真实字段核对：国家文件是数组；`sources.streams` 为 URL 数组；`sources.youtube` 可与其并存；`nanoid`、`country`、`isGeoBlocked` 与需求一致。
- 地球采用 `react-globe.gl`，国界来自 `world-atlas@2.0.2` 的 Natural Earth 1:110m 数据；通过 ISO 数字码显式转换为 alpha-2 代码。转换后 174 个地理要素可与国家代码直接关联。其余国家和地区保留在国家列表。
- 浏览器原生 HLS 优先，否则使用 `hls.js`。源限定为 HTTP(S) `.m3u8` 地址；实际能否播放尚未由此证明。
- 已实现多源状态与取消、WebGL 不可用列表回退，以及减少动态效果时停止自转。弱性能设备帧率尚未测试。
